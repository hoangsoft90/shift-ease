## 3. File đã sửa (kiểm tra trên đĩa bằng grep/sed)

- `lib/main.dart` — import `business_repository.dart`, dựng `ImportRepository(db, patterns)`, truyền `imports:`.
- `lib/domain/schedule_service.dart` — `commitRoster` transaction-atomic, gọi `_importRepo._saveSessionInTransaction`, gắn window before commit.
- `lib/core/import/import_types.dart` — field `windowStart`/`windowEnd`, `copyWith` mở rộng, comment window semantics.
- `lib/core/import/import_engine.dart` — commit gắn window từ `allDates` (shifts + OFF dates).
- `lib/core/db/business_repository.dart` — `saveSession`/`_saveSessionInTransaction` append cột `windowStart`,`windowEnd`, revert COALESCE jobId về dạng an toàn hơn, custom `ImportRepository(this.db, [this.jobs])`.
- `lib/core/db/schedule_repository.dart` — `committedOffDatesInRange` đổi query sang `BETWEEN windowStart AND windowEnd LIMIT 1`.
- `lib/core/db/pattern_repository.dart` — `ON CONFLICT(id) DO NOTHING` + read-back payload check.
- `lib/core/pattern/pattern_engine.dart` — SWAP dùng `effectiveJobId`, reject hard khi rỗng.
- `lib/core/time/time_types.dart` — thêm `ErrorCodes.incompleteSwap = 'INCOMPLETE_SWAP'`.
- `lib/features/import/import_screen.dart` — `_pendingCount`, `_pendingWarningSite`, ghi chú partial-commit trong `_sessionStatus`.
